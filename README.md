# 🚗 Smart On-Street Parking System

Smart On-Street Parking System, şehir içi park sorununu çözmeyi amaçlayan akıllı bir park yönetim sistemidir. Sistem, park alanlarının takibini ve yönetimini optimize ederek kullanıcıların uygun park yerlerini kolayca bulmasını sağlar.

## 🚀 Features

- 🅿️ Park alanı yönetimi
- 📍 Uygun park yeri bulma
- 📊 Gerçek zamanlı doluluk takibi
- 👤 Kullanıcı bazlı işlemler
- 🔍 Park alanı sorgulama

## 🧱 Architecture

- Katmanlı mimari (Layered Architecture)
- RESTful API yapısı
- Backend servisleri üzerinden veri yönetimi

## 🛠️ Technologies Used

- Java / Spring Boot
- REST API
- SQL (MySQL / Oracle)
- Backend Services
